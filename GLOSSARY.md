# Portafolio profesional

Este contexto define el lenguaje del sitio personal de Jaime Fabian Cortes Vega y distingue el contenido profesional confirmado de los espacios aún pendientes de completar.

## Contenido profesional

**Habilidades técnicas**:
Conocimientos tecnológicos y capacidades que la persona presenta en el portafolio, agrupados por área. Incluyen ciencia de datos, herramientas de análisis, desarrollo web, sistemas, cloud y bases de datos.
_Evitar_: Skills como etiqueta principal

**Proyecto provisional**:
Espacio reservado para un proyecto que todavía no tiene contenido verificable y que debe sustituirse antes de presentar el portafolio como completo.
_Evitar_: Proyecto ficticio, proyecto real

**Certificación provisional**:
Espacio reservado para una certificación aún no documentada, identificado únicamente con la leyenda “Ejemplo de certificación”.
_Evitar_: Certificación, credencial

## Datos pendientes

**Contacto pendiente**:
Dato de contacto o perfil externo que todavía no tiene un valor proporcionado por la persona y, por tanto, no debe mostrarse como enlace activable.
_Evitar_: Enlace roto, contacto ficticio

**Placeholder de perfil**:
Representación temporal y accesible del espacio destinado a la foto de perfil, sin contener una imagen personal no proporcionada.
_Evitar_: Foto generada, avatar real

## Experiencia visual

**Experiencia tipo videojuego**:
Lenguaje visual del portafolio que combina estética pixel art, movimiento de fondo y respuestas interactivas con una presentación profesional.
_Evitar_: Videojuego completo, navegación por pantallas

**Fondo animado**:
Capa decorativa en movimiento detrás del contenido principal, de baja opacidad y sin funciones de interacción.
_Evitar_: Fondo interactivo, contenido principal

**Sección activa**:
Sección vertical que el visitante está recorriendo principalmente y cuyo enlace correspondiente se resalta en la navegación.
_Evitar_: Página activa, menú seleccionado

**Sonido de selección**:
Efecto breve y opcional que confirma una interacción del visitante con la navegación, un botón o un elemento seleccionable, sin reproducción automática.
_Evitar_: Música de fondo, sonido automático
